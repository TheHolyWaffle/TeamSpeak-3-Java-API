# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to use the library, or discuss an idea | [Discussions](https://github.com/TheHolyWaffle/TeamSpeak-3-Java-API/discussions) (**Q&A** for questions) |
| Report a reproducible bug | [Bug report](https://github.com/TheHolyWaffle/TeamSpeak-3-Java-API/issues/new?template=bug_report.yml) |
| Propose a concrete change | [Feature request](https://github.com/TheHolyWaffle/TeamSpeak-3-Java-API/issues/new?template=feature_request.yml) |
| Report a vulnerability | Privately, as described in the [security policy](SECURITY.md) |
| Contribute code or documentation | [Contributing guide](CONTRIBUTING.md) |

Before asking, check the [README](README.md), the guides in [`docs/`](docs) and the
[examples](src/example/java/com/github/theholywaffle/teamspeak3/example). Questions about the
TeamSpeak server itself (licensing, configuration, ServerQuery permissions) belong in the
[TeamSpeak community](https://community.teamspeak.com).

The library is maintained by volunteers; there is no chat room and no guaranteed response time.
Only [supported versions](SECURITY.md#supported-versions) receive fixes.
